日本で Software Engineer として活動しております。

「ユーザーへのデリバリー価値の最大化」をミッションに掲げ、Web 技術を中心にインフラ・バックエンド・フロントエンド・開発ツーリング・AI Native な開発技術まで、幅広い技術を用いて課題解決に取り組んでいます。

現在はヘルステックの事業会社にて、複数のプロダクトチームに入り込む embedded 型のプラットフォームエンジニアとして、SLI/SLO の策定やエラーの自動トリアージ、開発生産性の向上に従事しています。約 1,000 万 MAU のサービスの Rails から Node.js へのリアーキテクト(レイテンシを中央値で従来の約 40% に短縮)や、LLM バッチ処理基盤の再構成といったプロジェクトに取り組んできました。あわせてコスメアプリのフロントエンドチームにも参画し、AI エージェントによって改善をスケールさせる開発基盤づくりを担当しています。

技術ドメインとしては、ビルドシステム・エッジコンピューティング・静的解析といった、アプリケーションを支える基盤レイヤーを得意としています。約 20 リポジトリのモノレポ統合や、エッジでのビルド・配信基盤の構築(スクリプトのバンドルサイズを約 90% 削減)などがその例です。ハイパフォーマンスな BFF やフロントエンドを実現するためのキャッシュ戦略、アプリケーションを超えインフラなどまで踏まえたサービス設計や、フロントエンド面での複雑なツーリングをアプリケーションの要件やチームの文化に応じて設計、導入することを生業としています。

特定のポジションに閉じず、チームのライフサイクルと技術的な現在地を読み取った上で、実際に前へ進む最小の打ち手を選ぶ embedded 型の動き方を続けてきました。技術的な意思決定を自分だけのものにせず、規約やガードレール・静的解析ルールとしてコード化し、チームに残る形で引き渡すことを重視しています。

また OSS 活動も行っており、個人のプロジェクトだとECMAScript におけるモジュールの副作用を発見するツール (Treeche) の開発や自作ブラウザの作成を行っています。pnpm のコアコントリビューターでもあり、タスクランナー周りの開発を主に行っていました。現在は Generative UI フレームワークである OpenUI に継続的にコミットしており、そのほか vitest・biome・oxc-project といった日常的に利用するツールへの上流貢献も続けています。
